发版文档工具 — 启动说明
========================

【双击 启动工具.bat 会发生什么】

1. 检测 5175 端口（工具自己的服务）
2. 没在跑 -> 后台启动 node app/server.js（最小化窗口，关掉该窗口即停止服务）
3. 打开浏览器到 http://127.0.0.1:5175 —— 这就是工具的界面
4. 起不来 -> 窗口会停下并给出手动启动命令

【界面里有什么】

- 更新说明 tab：选项目 → 填/勾功能点 → ①分析正文 → ②截图 → ③合成输出
- 需求转译 tab：贴需求 → ①出拷问清单 → 选择性回答 → ②生成五件套
- 右上角「设置」：DeepSeek API Key、各阶段模型参数、项目档案

【第一次使用必做】

右上角「设置」-> 粘贴 DeepSeek API Key -> 保存。
没有 Key 的话，git 候选和需求解析会退回原始模式（功能点需手填）。

【如果 bat 双击后闪退】

在 cmd 里手动运行看报错：
  cd /d "E:\Gouge2\轻量化agent转义"
  启动工具.bat
也可以手动启动服务：
  node "E:\Gouge2\轻量化agent转义\app\server.js"
然后浏览器开 http://127.0.0.1:5175
